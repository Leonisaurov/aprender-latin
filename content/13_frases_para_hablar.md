# 13 · Frases para hablar latín: tu banco conversacional

> Hablar latín no es recitar Cicerón: es pedir pan, saludar, opinar. Aquí tienes el
> banco de frases activo del proyecto, organizado por situación. Léelo en voz alta con
> las reglas del capítulo 02 (clásica por defecto).

## 1. Saludar y despedir

| Latín | Español |
|---|---|
| *Salvē!* / *Salvēte!* | ¡Hola! / ¡Hola (a varios)! |
| *Ave!* | ¡Salve! (a superior, solemne) |
| *Quid agis?* / *Quid agitis?* | ¿Qué tal? (lit. ¿qué haces?) |
| *Valeō, grātiās tibi agō.* | Estoy bien, gracias. |
| *Bene agō.* / *Nōn male.* | Voy bien. / No mal. |
| *Et tū?* | ¿Y tú? |
| *Valē!* / *Valēte!* | ¡Adiós! (vale = «estate fuerte») |
| *Bonam fortūnam!* | ¡Buena suerte! |
| *Cūrā tē bene.* / *Cūrā ut valeās.* | Cuídate. |
| *Bene tē!* / *Bene vōs!* | ¡Salud! (brindis) |
| *Ad multōs annōs!* | ¡Por muchos años! |

## 2. Presentarse y preguntar

| Latín | Español |
|---|---|
| *Mihi nōmen est Mārcus.* | Me llamo Marco. |
| *Quid tē nōmen est?* | ¿Cómo te llamas? |
| *Unde vēnistī?* | ¿De dónde vienes? |
| *E Hispaniā vēnī.* | Vengo de Hispania. |
| *Ubi habitās?* | ¿Dónde vives? |
| *Rōmae habitō.* | Vivo en Roma. |
| *Quot annōs habēs?* | ¿Cuántos años tienes? |
| *Vīgintī annōs habeō.* | Tengo veinte años. |
| *Quid facis?* | ¿Qué haces? |
| *Quō īs?* | ¿Adónde vas? |
| *Cūr?* | ¿Por qué? |
| *Quandō? / Ubi? / Quōmodo?* | ¿Cuándo? / ¿Dónde? / ¿Cómo? |
| *Quis? / Quid?* | ¿Quién? / ¿Qué? |
| *Quantum? / Quot?* | ¿Cuánto? / ¿Cuántos? |
| *Estne vērum?* | ¿Es verdad? |
| *Intellegisne?* | ¿Entiendes? |
| *Quid significat…?* | ¿Qué significa…? |
| *Nesciō.* / *Nesciō ubi sit.* | No sé. / No sé dónde está. |

## 3. Cortesía

| Latín | Español |
|---|---|
| *Grātiās tibi agō.* / *Grātiās vōbīs agimus.* | Gracias (ti/vosotros). |
| *Multās grātiās!* | ¡Muchas gracias! |
| *Nihil est.* / *Nōn est cūrae.* | No hay de qué. |
| *Quaesō.* | Por favor. |
| *Amābō tē.* | Por favor (afectuoso, lit. «te amaré»). |
| *Ignōsce mihi.* | Perdóname. |
| *Mihi placet.* / *Nōn mihi placet.* | Me gusta. / No me gusta. |
| *Licetne mihi…?* | ¿Me es permitido…? |
| *Licet.* / *Nōn licet.* | Puedes. / No puedes. |
| *Sī placet.* | Si te place (encantado). |
| *Bene dīcis!* / *Optimē!* | ¡Bien dices! / ¡Excelente! |
| *Prōrsus vērum!* | ¡Completamente cierto! |
| *Minimē!* / *Nūllō modō!* | ¡Para nada! / ¡De ninguna manera! |
| *Fortasse.* / *Forsitan.* | Quizá. |
| *Nesciō.* | No sé. |

## 4. En la mesa

| Latín | Español |
|---|---|
| *Esuriō.* | Tengo hambre. |
| *Sitīs (est).* | Tengo sed. |
| *Quid ēdimus?* | ¿Qué comemos? |
| *Vīsne pānem?* | ¿Quieres pan? |
| *Volō vīnum et aquam.* | Quiero vino y agua. |
| *Nōn volō.* / *Satis mihi est.* | No quiero. / Me basta. |
| *Bene sapit!* | ¡Sabe bien! |
| *Ō dulce!* / *Ō miserum!* | ¡Qué rico! / ¡Qué malo! |
| *Grātiās cēnae!* | ¡Gracias por la cena! |
| *Aquam quaesō.* | Agua, por favor. |

## 5. Compras y números

| Latín | Español |
|---|---|
| *Quantī cōnstat?* | ¿Por cuánto está? |
| *Dēnāriō* | Por un denario. |
| *Dēnāriīs decem* | Por diez denarios. |
| *Nimium cārum est!* | ¡Es demasiado caro! |
| *Vīlīs est.* | Es barato. |
| *Emō.* / *Nōn emō.* | Lo compro. / No lo compro. |
| *Numerī útiles:* | **ūnus, duo, trēs, quattuor, quīnque, sex, septem, octō, novem, decem, vīgintī, centum, mīlle** |

## 6. Tiempo, clima y cuerpo

| Latín | Español |
|---|---|
| *Quot hōrae sunt?* | ¿Qué hora es? (lit. ¿cuántas horas son?) |
| *Hōra tertia est.* | Es la tercera hora (≈ 9 de la mañana). |
| *Sōl orītur.* / *Sōl occīdit.* | Amanece. / Anochece. |
| *Cālum serēnum est.* | El cielo está sereno. |
| *Pluit.* / *Ningit.* | Llueve. / Nieva. |
| *Calidum est.* / *Frīgidum est.* | Hace calor. / Hace frío. |
| *Caput dolet.* | Me duele la cabeza. |
| *Aegrōtus sum.* / *Sānus sum.* | Estoy enfermo. / Estoy sano. |
| *Esuriō* ya está; *Sitīs est.* | Tengo sed. |

## 7. Opinar, hablar de todo

| Latín | Español |
|---|---|
| *Putō…* / *Crēdō…* | Creo que… |
| *Nōn putō.* | No lo creo. |
| *Mihi vidētur…* | Me parece que… |
| *Quid cēnsēs?* | ¿Qué opinas? |
| *Vērum dīcis.* | Dices la verdad. |
| *Falsum est.* | Es falso. |
| *Nōn intellegō.* | No entiendo. |
| *Intellegō omnīa!* | ¡Entiendo todo! |
| *Quid novī?* | ¿Qué hay de nuevo? |
| *Nihil novī.* | Nada de nuevo. |
| *Quam pulchrum!* / *Quam magnum!* | ¡Qué bonito! / ¡Qué grande! |
| *Miserē!* | ¡Pobre (de ti)! / ¡Ay! |
| *Hercule!* | ¡Por Hércules! |

## 8. Conectores que dan fluidez

*et* (y) · *-que* (y, postpuesto: *senātus populusque*) · *atque/ac* (y además) ·
*sed* (pero) · *autem* (en cambio) · *at* (pero) · *aut… aut* (o… o) · *vel… vel* (o…) ·
*nam / enim* (pues, porque) · *quia / quod* (porque) · *igitur / ergo / itaque* (por
tanto) · *tamen* (sin embargo) · *igitur* al final de frase · *vērō* (en realidad) ·
*quidem* (ciertamente) · *immō* (antes bien) · *fortasse* (quizá) · *scilicet*
(naturalmente) · *dēnique / tandem* (por fin) · *item* (igualmente) · *praeterea*
(además).

## 9. En el aula de latín (¡para hablar CONMIGO!)

| Latín | Español |
|---|---|
| *Loquere mecum Latīnē!* | ¡Habla conmigo en latín! |
| *Latīnē loquī possum.* | Puedo hablar latín. |
| *Paululum Latīnē loquor.* | Hablo un poco de latín. |
| *Quōmodo dīcitur «…» Latīnē?* | ¿Cómo se dice «…» en latín? |
| *Quid significat «…»?* | ¿Qué significa «…»? |
| *Nōn cognōscō hanc vocem.* | No conozco esta palabra. |
| *Tardē loquere, quaesō.* | Habla despacio, por favor. |
| *Iterum dīc, quaesō.* | Repite, por favor. |
| *Emendā mē, sī errō.* | Corrígeme si me equivoco. |
| *Quid est hoc Latīnē?* | ¿Qué es esto en latín? |
| *Declinā mihi «mēnsam»!* | ¡Declíname «mesa»! |
| *Lēgē hanc fābulam!* | ¡Lee esta fábula! |
| *Scribe mihi exercitium!* | ¡Escríbeme un ejercicio! |
| *Difficile est, sed fortis sum.* | Es difícil, pero soy fuerte. |

## 10. Citas para la vida (con fuente)

| Cita | Fuente | Sentido |
|---|---|---|
| *Carpe diem, quam minimum crēdula posterō.* | Horacio, *Od.* I 11 | Aprovecha el día. |
| *Festīnā lentē.* | Suetonio, *Aug.* 25 | Apúrate despacio. |
| *Dum spīrō, spērō.* | Cicerón, *Ad Att.* IX 10 | Mientras respiro, espero. |
| *Errāre hūmānum est.* | proverbio antiguo (cf. Publio Sirio) | Equivocarse es humano. |
| *Vērba volant, scrīpta manent.* | proverbio (forma medieval) | Lo escrito permanece. |
| *Mēns sāna in corpore sānō.* | Juvenal, *Sát.* X 356 | Mente sana en cuerpo sano. |
| *Bis dat, quī citō dat.* | proverbio | Da dos veces quien da pronto. |
| *Sī vīs pācem, parā bellum.* | adaptación de Vegetio | Si quieres paz, prepara la guerra. |
| *Ōtium post negōtium.* | proverbio | El descanso tras el trabajo. |
| *Audentēs Fortūna iuvat.* | Virgilio, *En.* X 284 | La Fortuna ayuda a los audaces. |
| *Per aspera ad astra.* | adaptación de Séneca | Por lo duro, a las estrellas. |
| *Mementō morī.* | tradición antigua | Recuerda que morirás. |
| *Quidquid agis, prūdenter agās et respice fīnem.* | proverbio medieval | Lo que hagas, hazlo con cuidado y mira el final. |

*(N.B. Varias citas clásicas «modernas» — *cogito ergo sum* de Descartes, *et tu,
Brute* fijada por Shakespeare — son de otras épocas: úsalas sabiendo su historia.)*

## 11. Mini-diálogo de supervivencia (apréndetelo HOY)

> — *Salvē! Quid tē nōmen est?*  
> — *Mihi nōmen est Gāius. Tū quis es?*  
> — *Sum Lūcius. Unde vēnistī?*  
> — *Rōmā vēnī. Et tū?*  
> — *Ego Capuā. Quō īs hodiē?*  
> — *Ad forum eō, ut pānem emam.*
> — *Ego tēcum eō. Loquere mecum Latīnē!*  
> — *Libenter! Latīnē loquī mihi grātum est.*

Traducción: — ¡Hola! ¿Cómo te llamas? — Me llamo Cayo. ¿Tú quién eres? — Soy Lucio.
¿De dónde vienes? — Vengo de Roma. ¿Y tú? — Yo de Capua. ¿Adónde vas hoy? — Voy al
foro, para comprar pan. — Voy contigo. ¡Habla latín conmigo! — ¡Con gusto! Hablar
latín me agrada.

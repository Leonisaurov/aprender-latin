## Grammatica

### 1. Adjetivos de 3.ª clase (repaso del cap. 04)

| Paradigma | m./f. | n. | Español |
|---|---|---|---|
| Dos terminaciones | fortis | forte | fuerte |
| Dos terminaciones | omnis | omne | todo |
| Tres terminaciones | ācer, ācris | ācre | agudo |
| Una terminación | fēlīx, fēlīcis | fēlīx | feliz |

Gen. pl. en **-ium** (*fortium*), abl. sg. **-ī** (*fortī*), neutro pl. **-ia** (*omnia*).

### 2. Comparativo: «más… que»

Tema + **-ior** (m./f.) / **-ius** (n.); gen. sg. **-iōris** (3.ª declinación):

- *brevis → brevior, brevius* «más corto» · *pulcher → pulchrior* «más bonito».
- «Más… QUE» = **quam** + mismo caso, O ablativo solo:
  *Via brevior est quam illa* · *Mārcus fortior est quam Sextus* = *Mārcus Sextō
  fortior est*.
- Irregulares: *bonus → melior* (mejor), *malus → peior* (peor), *magnus → maior*
  (mayor), *parvus → minor* (menor), *multus → plūs* (más).

### 3. Superlativo: «el más… / -ísimo»

**-issimus, -a, -um**: *longissimus*, *fortissimus*. Con -er: **-errimus**
(*pulcherrimus*, *celerrimus*). Con -lis: **-illimus** (*facillimus*).

Irregulares: *bonus → optimus*, *malus → pessimus*, *magnus → maximus*, *parvus →
minimus*. «El más… DE» = **genitivo**: *Rōma omnium urbium maxima est* «Roma es la
mayor de todas las ciudades».

### 4. Adverbios

- De adjetivo -us → **-ē**: *lentē* «lentamente»; de -lis → **-iter**: *fortiter*,
  *celeriter*.
- Comparativo adverbial = comparativo neutro: *celerius* «más rápido».
- Superlativo adverbial: **-issimē**: *fortissimē* «con la mayor fuerza».
- Irregulares: *bene → melius → optimē*; *male → peius → pessimē*.

### 5. Demostrativos: los tres «ese»

| | «este» | «aquel» | «ese / él» |
|---|---|---|---|
| Nom. sg | hic / haec / hoc | ille / illa / illud | is / ea / id |
| Acus. sg | hunc / hanc / hoc | illum / illam / illud | eum / eam / id |
| Gen. sg | huius | illīus | eius |
| Dat. sg | huic | illī | eī |
| Abl. sg | hōc / hāc | illō / illā | eō / eā |
| Acus. pl | hōs / hās / haec | illōs / illās / illa | eōs / eās / ea |

*Hanc viam cape* «toma ESTA calle» · *in illā viā* «en AQUELLA calle» ·
*is puer* «ese niño» / solo *is* = «él». Adverbios: *hīc* (aquí), *illīc* (allí),
*hūc* (hacia aquí), *illūc* (hacia allí).

## Lectio — Fabula Aesopea: *Vulpes et Uvae*

> Vulpēs ēsurit. Uvae altae in arbore pendent.
> Vulpēs salit; uvās attingere nōn potest.
> Iterum salit; iterum nōn potest.
> Tum vulpēs dīcit: «Uvae acerbae sunt! Nōn volō ēdere uvās acerbas.»
> Et trīstis discēdit.
> Mōrālis: quod attingere nōn possumus, id saepe malum dīcimus.

**Glosario:** *vulpēs, vulpis, f.* zorra · *ēsuriō, -īre* tener hambre · *uva* uva ·
*arbor, arboris, f.* árbol · *altus* alto · *pendeō, pendēre* colgar · *saliō, salīre*
saltar · *attingō, -ere* alcanzar · *iterum* otra vez · *acerbus* verde, áspero ·
*trīstis* triste, cabizbaja · *discēdō, discēdere* marcharse · *malum* malo.

## Cultura Romana — Las calles de Roma

Las calles urbanas (*viae*) eran estrechas, pavimentadas con bloques de basalto
(*sīlex*), con aceras (*crepidinēs*) y pasos de piedras saltarinas en los cruces — las
ruedas pasaban por los huecos. Había *lacus* (fuentes públicas de agua) cada pocas
cuadras, y paredes llenas de graffiti electoral: «¡Vota a X, buen hombre!». Las
grandes **viae militārēs** unían el imperio: la **Via Appia**, «*regina viārum*» (la
reina de los caminos), iba de Roma a Brindis; «todos los caminos llevan a Roma» en
serio: los miliarios marcaban las millas desde el *Milliarium Aureum* del Foro.

## Pronūntia

- *via*: UÍ-a (¡v = u!). · *pulcherrimus*: pul-KÉR-ri-mus.
- *celeriter*: ke-le-RÍ-ter. · *ille*: ÍL-le (e corta) — no «ílle».
- Clásica: *amicus* a-MÍ-kus; *fortuna* for-TU-na (u breve).
